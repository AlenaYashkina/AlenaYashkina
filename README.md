## Operational systems I've built

### [Connected property-management workspace — Supabase, ChatGPT & Jira](cases/property-management-automation.md)

A working set of tools for coordinating rentals, guest communication, property records and tasks:

- **Structured operational database (Supabase):** apartments, contacts, bookings, payment references, utilities, channel listings and linked Telegram conversations.
- **ChatGPT as a working interface:** connected plugins retrieve apartment details and message history, identify new guest requests, and help prepare replies for staff review.
- **Jira workflows and Forge integration:** custom property selection linked to Supabase; task assignments, incidents, priorities, follow-ups, and automation.
- **Expenses and owner reporting:** Google Sheets / Apps Script interfaces for costs and staff reimbursements; booking import, owner-share and exchange-rate calculations, PDF reports.
- **Scheduled Telegram listings:** management of destination chats, properties, text, photos and a publication queue, including background execution and recovery.

The case describes real workflows using **anonymized examples**, without disclosing guest or company information. Booking imports are reconciled from provider exports because an integration API has not been made available to the team; I do not claim real-time synchronization.
